# 🛒 E-Commerce Website

A fully responsive **E-Commerce Website** built using web technologies. This project provides an online shopping experience where users can browse products, add items to cart, and view purchase details with a clean and user-friendly interface.

---

## 🚀 Features

✨ Responsive Design (Mobile & Desktop Friendly)
✨ Product Listing with Images & Prices
✨ Add to Cart Functionality
✨ Shopping Cart Page
✨ Navigation Menu
✨ Modern UI with Animations
✨ Easy Customization

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap (Optional)
